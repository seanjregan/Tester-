# X Header Asset Source for `@agentsgowild`

## Recommended source image (highest broadly available public copy)
- Source: https://upload.wikimedia.org/wikipedia/en/1/11/Disaster_Girl.jpg
- Context page: https://en.wikipedia.org/wiki/Disaster_Girl

## X header sizing target
- Final canvas: **1500 x 500 px** (3:1)
- Keep key subject (face) inside center safe area to avoid cropping on mobile.

## Fast workflow to produce upload-ready header
1. Download source image from the URL above.
2. In Canva, Figma, or Photoshop create a 1500x500 canvas.
3. Place the image, scale until the face sits on right-third and fire stays visible left-third.
4. Export as JPG (quality 85–90) under ~2 MB.
5. Upload in X profile header and preview on desktop + mobile.
