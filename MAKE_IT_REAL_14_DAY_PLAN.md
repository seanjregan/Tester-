# Agents Gone Wild — 14-Day Execution Plan to Make It Real

## Goal
Launch publicly with Episode 1, build repeatable weekly cadence, and prove audience traction.

## Day 1–2: Foundation
- Finalize visual identity (logo, header, thumbnail style).
- Set profile bio + pinned post on X and LinkedIn.
- Create one shared operating board (Notion/Airtable):
  - episode pipeline
  - incident tracker
  - publish calendar

## Day 3: Trailer Production
- Record 60-second trailer.
- Edit two cuts (60s + 30s).
- Add captions.
- Publish trailer to X + LinkedIn.

## Day 4: Book and prep the interview
- Confirm Jeremy Crane interview time.
- Send prep note with topics and boundaries.
- Finalize question order from Episode 1 script.

## Day 5: Record Episode 1
- Record 10-minute interview.
- Record 2 additional short vertical clips after main interview.
- Capture one strong pull-quote for thumbnail/title.

## Day 6: Edit + package
- Finalize full episode (6–12 min).
- Cut two short clips.
- Draft:
  - one X thread
  - one LinkedIn post
  - one comments CTA

## Day 7: Publish Episode 1
- Post full episode.
- Publish X thread and LinkedIn summary post.
- Reply to comments for first 60–90 minutes.

## Day 8: Analyze
- Measure:
  - 3s/30s retention
  - saves + shares
  - comments quality
- Document what worked and what dropped off.

## Day 9–10: Episode 2 pre-production
- Pick next incident from tracker.
- Outline episode using same structure:
  - what happened
  - why it happened
  - prevention

## Day 11: Build templates once
- Create reusable templates:
  - thumbnail
  - episode description
  - X thread skeleton
  - LinkedIn post skeleton

## Day 12: Audience flywheel
- Launch a recurring call for incidents:
  - weekly X post asking for submissions
  - LinkedIn prompt for practitioner stories

## Day 13: Reliability + risk controls
- Add internal pre-publish checklist:
  - source verification
  - legal/privacy check
  - speculation labeling
  - correction note format

## Day 14: Weekly operating cadence lock-in
- Set fixed weekly schedule:
  - research day
  - recording day
  - edit day
  - publish day
- Commit to 4-week sprint before major format changes.

---

## Success criteria by end of day 14
- Episode 1 published.
- Trailer published.
- At least 2 short clips published.
- Episode 2 selected and outlined.
- Repeatable weekly workflow running.

## If you only do one thing today
Record and publish the trailer. Public momentum beats private perfection.
